

# Exercício 05 - Tabuada de multiplicação com Laço `for`

## 📖 Descrição

Este programa solicita ao usuário um número inteiro e exibe a tabuada de multiplicação desse número de **1 a 10** utilizando um laço de repetição `for`.

## 🎯 Objetivo

Praticar a utilização de estruturas de repetição em Java, permitindo gerar automaticamente a tabuada de qualquer número informado pelo usuário.

## 📋 Requisitos

* Ler um número inteiro informado pelo usuário.
* Utilizar a classe `Scanner` para entrada de dados.
* Utilizar um laço `for` para repetir a operação 10 vezes.
* Exibir a tabuada no formato:

```text
5 x 1 = 5
5 x 2 = 10
...
5 x 10 = 50
```

## 🧠 Conceitos aplicados

* Variáveis
* Entrada de dados com `Scanner`
* Estrutura de repetição `for`
* Operadores aritméticos (`*`)
* Saída de dados com `System.out.println()`

## ▶️ Exemplo de execução

**Entrada:**

```text
Digite o primeiro número:
7
```

**Saída:**

```text
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
7 x 6 = 42
7 x 7 = 49
7 x 8 = 56
7 x 9 = 63
7 x 10 = 70
```
