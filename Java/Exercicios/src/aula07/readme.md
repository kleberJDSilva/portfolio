# Exercício 07 - Exibição de Números Pares com Laço `for`

## 📖 Descrição

Este programa exibe todos os números pares no intervalo de **0 a 60**. Para isso, utiliza um laço de repetição `for` para percorrer todos os números do intervalo e uma estrutura condicional `if` para verificar se cada número é par.

## 🎯 Objetivo

Praticar a utilização de laços de repetição e estruturas condicionais para percorrer uma sequência numérica e filtrar apenas os valores que atendem a uma determinada condição.

## 📋 Requisitos

* Percorrer os números de **0 a 60** utilizando um laço `for`.
* Verificar se cada número é par utilizando o operador módulo (`%`).
* Exibir apenas os números pares encontrados.
* Apresentar os resultados no console.

## 🧠 Conceitos aplicados

* Estrutura de repetição `for`
* Estrutura condicional `if`
* Operador módulo (`%`)
* Operadores relacionais (`==`)
* Saída de dados com `System.out.println()`
