
# Exercício 06 - Comparação entre Dois Números

## 📖 Descrição

Este programa solicita ao usuário dois números inteiros e realiza uma comparação entre eles. Ao final, informa se os números são iguais ou qual deles possui o maior valor.

## 🎯 Objetivo

Praticar a utilização de estruturas condicionais em Java para comparar valores e tomar decisões com base no resultado das comparações.

## 📋 Requisitos

* Ler dois números inteiros informados pelo usuário.
* Utilizar a classe `Scanner` para entrada de dados.
* Comparar os valores utilizando estruturas condicionais (`if`, `else if` e `else`).
* Exibir uma mensagem informando:

  * Se os números são iguais.
  * Ou qual dos dois números é o maior.

## 🧠 Conceitos aplicados

* Variáveis
* Entrada de dados com `Scanner`
* Estruturas condicionais (`if`, `else if` e `else`)
* Operadores relacionais (`==` e `>`)
* Saída de dados com `System.out.println()`

## ▶️ Exemplo de execução

**Entrada:**

```text
Digite o primeiro número:
15

Digite o segundo número:
20
```

**Saída:**

```text
O número 20 é maior.
```

### Outro exemplo

**Entrada:**

```text
Digite o primeiro número:
8

Digite o segundo número:
8
```

**Saída:**

```text
Os números são iguais.
```
