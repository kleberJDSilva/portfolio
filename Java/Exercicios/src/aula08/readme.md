# Exercício 08 - Identificação do Maior e Menor Número

## 📖 Descrição

Este programa solicita ao usuário cinco números inteiros e identifica qual é o maior e o menor valor informado. Para isso, utiliza um laço de repetição `for`, comparando cada número digitado com os valores armazenados nas variáveis `maior` e `menor`.

## 🎯 Objetivo

Praticar a utilização de estruturas de repetição e condicionais para comparar valores durante a execução do programa, atualizando o maior e o menor número encontrados sem a necessidade de criar várias variáveis.

## 📋 Requisitos

* Ler cinco números inteiros informados pelo usuário.
* Utilizar a classe `Scanner` para entrada de dados.
* Utilizar um laço `for` para realizar as leituras.
* Comparar cada número com os valores armazenados nas variáveis `maior` e `menor`.
* Exibir o maior e o menor número ao final da execução.

## 🧠 Conceitos aplicados

* Variáveis
* Entrada de dados com `Scanner`
* Estrutura de repetição `for`
* Estruturas condicionais (`if`)
* Operadores relacionais (`>` e `<`)
* Atualização de variáveis durante a execução
* Saída de dados com `System.out.println()`

## ▶️ Exemplo de execução

**Entrada:**

```text
Digite um número: 15
Digite um número: 8
Digite um número: 22
Digite um número: 10
Digite um número: 5
```

**Saída:**

```text
Maior número: 22
Menor número: 5
```

## 🚀 Aprendizados

Durante este exercício foi possível compreender como utilizar um laço de repetição para processar múltiplos valores sem criar diversas variáveis. Também foi reforçado o conceito de atualização de variáveis durante a execução do programa, armazenando sempre o maior e o menor valor encontrados até o momento. Esse tipo de lógica é amplamente utilizado em algoritmos que percorrem listas, vetores, coleções e consultas a bancos de dados.
