# Exercício 02 - Soma de dois números

## Descrição

Programa desenvolvido em Java que realiza a soma de dois números inteiros 
e exibe o resultado no console.

## Objetivo

Praticar a criação de variáveis, armazenamento de valores inteiros,
realização de operações matemáticas e impressão de resultados utilizando
o método System.out.println().

## Requisitos

- Criar uma aplicação Java.
- Declarar duas variáveis do tipo inteiro.
- Realizar a soma entre os valores armazenados.
- Exibir o resultado da operação no console.

## Conceitos aplicados

- Estrutura básica de uma classe Java.
- Método main().
- Declaração de variáveis.
- Tipo de dado int.
- Operadores matemáticos (+).
- Concatenação de textos.
- Saída de dados com System.out.println().
